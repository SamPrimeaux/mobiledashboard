# Phase 01 — CMS Component Library

Build a minimal reusable CMS component library.

Write only inside:
- packages/cms-components/
- packages/cms-schemas/

Required components:
- DashboardShell
- CmsHeader
- CmsHero
- FeatureGrid
- DonationCTA
- StatsBand
- Footer
- SectionRenderer

Required schemas:
- sectionSchemas
- themeSchema
- artifactSchema
- pageTemplateSchema

Requirements:
- dark minimal style
- schema-driven props
- no emojis
- clean exports
- simple JSDoc comments
- no live API calls in components
